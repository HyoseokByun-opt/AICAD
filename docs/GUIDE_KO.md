# AICAD 사용자 가이드

AICAD(AI-assisted CAD Modelling)는 설비·부품 도면(PDF, 이미지, DXF)이나 글로 쓴 설명을 읽어 3D 솔리드 모델을
만들고 STEP 파일로 내보내는 프로그램이다. 도면 판독과 모델 코드 작성은 PC의 GPU에서 실행되는 비전-언어 모델
(Qwen3.6)이 맡고, 형상 생성은 OpenCASCADE 커널 위의 CadQuery가 맡는다. 모든 처리는 PC 안에서 이루어지며
인터넷 연결이 필요하지 않다.

## 1. 구성

| 폴더 / 파일 | 내용 |
|---|---|
| `1_INSTALL_OFFLINE.bat` | 오프라인 설치 (Python 런타임과 패키지를 `python\`에 설치) |
| `2_RUN_AICAD.bat` | 프로그램 실행 (브라우저가 `http://127.0.0.1:8100`으로 열린다) |
| `3_GET_AI_MODEL.bat` | AI 모델 다운로드 (인터넷이 되는 PC에서 실행) |
| `4_SELF_TEST.bat` | 설치 점검 (`--ai`를 붙이면 AI 모델까지 점검) |
| `5_RUN_SERVER.bat` | 사내망의 다른 PC에서 접속할 수 있도록 실행 |
| `engine\` | llama.cpp AI 엔진 (CUDA 12.4, Vulkan, CPU) |
| `models\` | AI 모델 (모델별 폴더) |
| `workspace\` | 프로젝트 저장 위치 (설정에서 변경 가능) |
| `examples\` | 예제 도면과 기준 모델 |

## 2. 설치

1. 배포 파일 `AICAD-0.1.0-offline-win64.zip`을 `C:\AICAD`처럼 짧은 경로에 푼다.
   경로가 길면 Windows의 경로 길이 제한(260자)에 걸릴 수 있다.
2. `1_INSTALL_OFFLINE.bat`을 실행한다. 관리자 권한과 인터넷은 필요하지 않다. 설치가 끝나면 자체 점검이
   실행된다. `python\` 폴더를 지우면 설치 이전 상태로 돌아간다.
3. 인터넷이 되는 PC에서 `3_GET_AI_MODEL.bat`을 실행하고 사용할 PC의 GPU에 맞는 모델을 고른다.
   - 1번: RTX 4090 (24 GB) → Qwen3.6-27B Q4_K_M (약 17.7 GB)
   - 2번: RTX 6000 Ada / A6000 Ada (48 GB) → Qwen3.6-27B Q6_K (약 23.5 GB)
   - 3번: 위 두 가지 모두 (두 PC에서 모두 쓸 경우)

   다운로드는 중단되어도 다시 실행하면 이어서 받으며, 모든 파일은 SHA-256으로 검증된다. 사내 프록시가 필요하면
   환경 변수 `HTTPS_PROXY`를 설정한다. 받은 `models\` 폴더를 오프라인 PC의 AICAD 폴더에 복사한다.
4. `2_RUN_AICAD.bat`으로 실행한다. 이 창을 닫으면 프로그램과 AI 엔진이 함께 종료된다.

NVIDIA 드라이버는 CUDA 12.4를 지원해야 한다(551.61 이상). 프로그램은 GPU 메모리를 확인하여 설치된 모델 중
가장 적합한 것을 자동으로 고른다.

## 3. 화면 구성

- **제목 표시줄**: 프로젝트 이름, AI 엔진 상태, Generate(생성)와 Stop(중지) 버튼.
- **리본**: Home, Drawing, Model, AI, Export, Settings 탭별 명령.
- **왼쪽 패널**: 리본 탭에 따른 입력과 설정 (요청, 도면 정보, 버전, AI 엔진, 내보내기, 설정).
- **가운데**: 3D Model, Drawing(도면), Compare(비교), Code(코드), Dimensions(치수표) 탭.
- **오른쪽 패널**: Inspector(모델 정보, 선택한 면), Parameters(파라미터), Parts(어셈블리 구성품).
- **아래 도크**: Console(진행 기록), AI output(AI가 생각하고 답하는 내용), Engine log(엔진 기록).

## 4. 도면으로 모델 만들기

1. **도면 가져오기**: 파일을 창에 끌어다 놓거나 Home → Import drawing을 누른다. PDF는 여러 쪽을 모두 읽으며,
   CAD에서 출력한 벡터 PDF는 치수 숫자를 파일에서 정확히 읽는다. DXF는 모델 공간을 그대로 그리고 치수 객체의
   측정값과 실제 축척을 사용한다.
2. 필요하면 **Description and instructions** 칸에 도면에 없는 정보를 적는다
   (예: "판 두께는 12 mm, 구멍은 모두 관통"). 이 내용은 도면보다 우선한다.
3. **Generate**를 누른다. 진행 순서는 다음과 같다.
   - 도면 판독: 투영법, 각 뷰의 종류와 위치, 적힌 치수, 모델링 순서, 치수가 없는 부분의 측정 위치를 읽는다.
   - 축척 계산과 비율 측정: 뷰 상자를 도면의 외곽선에 맞추고, 전체 치수와 뷰의 픽셀 크기로 축척(mm/픽셀)을
     구한 뒤, 치수가 없는 부분을 도면에서 재어 실제 크기로 환산한다.
   - 코드 작성: AI가 CadQuery 스크립트를 작성한다. 모든 치수는 파라미터 블록에 이름과 출처와 함께 적힌다.
   - 빌드와 오류 수정: 스크립트를 실행해 솔리드를 만들고, 실패하면 오류와 줄 번호를 AI에 돌려주어 고친다.
   - 도면 비교와 보정: 모델을 도면과 같은 방향으로 투영하여 전체 크기와 각 뷰의 외곽 형상을 비교하고,
     도면과 모델을 나란히 놓은 그림을 AI에 보여주어 수정한다. 가장 잘 맞는 버전이 현재 버전이 된다.
4. 결과는 3D Model 탭에 표시되고, 모든 빌드는 버전(v001, v002 …)으로 남는다.

**Read drawing only**는 판독까지만 수행한다. 치수표를 먼저 검토·수정한 뒤 **Build model from these values**로
모델을 만들 수 있다.

## 5. 설명으로 모델 만들기

도면 없이 Description 칸에 설명을 쓰고 Generate를 누른다. 주어지지 않은 치수는 표준 규격이나 일반적인 비율로
정해지고 `assumed`로 표시된다. 예:

> 수직 저장 탱크. 외경 800 mm, 직동부 높이 1500 mm, 위아래 2:1 반타원형 경판. 100 x 100 mm 각관 다리 4개가
> 45° 간격으로 하부 경판 아래 400 mm까지 내려온다. 상부 중앙에 100A 노즐(외경 114.3 mm) 높이 150 mm.

## 6. 결과 검토

### 6.1 치수표 (Dimensions 탭)

AI가 읽은 모든 값과 출처가 표시된다.

| 출처 | 의미 |
|---|---|
| `drawing` | 도면에 적힌 값 |
| `ratio` | 도면에서 길이를 재고 축척으로 환산한 값 |
| `user` | 사용자가 입력하거나 수정한 값 |
| `description` | 설명에 적힌 값 |
| `assumed` | 적혀 있지도, 잴 수도 없어 정한 값 |

값을 고치고 **Save changes**를 누르면 `user`로 표시된다. **Build model from these values**는 다시 판독하지 않고
이 표로 모델을 만든다. AI가 확인을 원하는 사항은 Open questions에 표시된다.

### 6.2 도면 (Drawing 탭)

- **Views**: AI가 찾은 뷰 상자. **Edit view boxes**로 상자를 옮기거나 크기를 바꿀 수 있으며, 손으로 놓은 상자는
  다시 자동 보정되지 않는다. 왼쪽 패널에서 뷰 종류(front, top, right …)를 바꿀 수 있다. 변경하면 축척과
  측정값이 다시 계산된다.
- **Measured sizes**: 비율로 잰 길이가 도면 위에 표시된다.
- **Measure**: 두 점을 찍어 도면 위 거리를 잰다(Shift: 수평/수직).
- **Calibrate**: 실제 거리를 아는 두 점을 찍고 그 거리를 입력하면 그 값이 축척으로 우선 사용된다.
  치수가 거의 없는 도면에서 유용하다.

여러 뷰에서 구한 축척이 8 % 이상 다르면 경고가 표시된다. 도면이 축척대로 그려지지 않았거나(NTS), 뷰 상자가
어긋났거나, 치수를 잘못 읽은 경우이다.

### 6.3 비교 (Compare 탭)

축별 전체 크기(모델 대 도면)와 뷰별 외곽 일치도(1 = 동일)가 표시된다. 거울상으로 뒤집었을 때 더 잘 맞으면
그 뷰에 표시가 붙는다. **Refine against drawing**을 누르면 AI가 차이를 보고 다시 수정한다.

## 7. 모델 수정

- **Parameters** (오른쪽 패널): 값을 바꾸고 Apply를 누르면 AI 없이 즉시 다시 빌드된다.
- **Change the model by instruction** (AI 탭): 말로 수정을 요청한다.
  예: "베이스 판을 5 mm 더 두껍게 하고 윗면 모서리에 2 mm 모따기, 구멍 4개는 M12 볼트용 13.5 mm로".
- **Code** 탭: 스크립트를 직접 고치고 Build this code(Ctrl+Enter)를 누른다. 오류가 나면 해당 줄이 표시된다.
- **Versions** (Home 또는 Model 탭): 이전 버전을 눌러 그 버전에서 이어서 작업할 수 있다.

## 8. 3D 보기

- 마우스 왼쪽 끌기: 회전, 오른쪽 끌기: 이동, 휠: 확대·축소.
- 표시 방식: Shaded + edges, Shaded, Wireframe, X-ray.
- Section: X/Y/Z 단면과 위치 슬라이더, ⇄로 방향 전환. 잘린 면은 주황색으로 표시된다.
- 면을 클릭하면 Inspector에 면의 종류, 면적, 원통면이면 지름과 축이 표시된다. 구멍 지름 확인에 쓴다.
- Measure: 모델 위 두 점의 거리와 ΔX, ΔY, ΔZ.
- Dims: 전체 치수 상자. Ortho: 정투영/원근 전환. 카메라 버튼: 화면 저장(PNG).

## 9. 내보내기 (Export 탭)

| 형식 | 내용 |
|---|---|
| STEP | 정확한 B-rep 솔리드, mm, 부품 이름 포함. AP214(기본), AP203, AP242 선택. 어셈블리는 구성품과 색상 유지 |
| STL | 3D 프린팅·메시용 (허용 오차 지정) |
| glTF (GLB) | 시각화용 |
| BREP | OpenCASCADE 고유 형식 |
| DXF | 정면·평면·우측면 2D 도면 (은선, 전체 치수) |
| .py / .zip | 모델 스크립트, 버전 전체 파일 묶음 |

## 10. AI 설정 (AI 탭, Settings 탭)

- **모델 선택**: Automatic은 GPU 메모리에 맞는 가장 좋은 모델을 고른다.
- **Thinking**: 판독·코드 작성·수정 요청 시 먼저 생각하게 하면 정확도가 오르지만 시간이 늘어난다.
  오류 수정 단계는 기본적으로 꺼져 있다. CPU 엔진에서는 항상 꺼진다.
- **Context length / Image detail**: 0이면 모델 프로필 값을 쓴다. 큰 도면의 작은 글자를 읽어야 하면
  Image detail을 늘린다.
- **Stop the engine when idle**: 지정한 시간 동안 요청이 없으면 GPU 메모리를 비운다.
- **Correction attempts / Refinement rounds**: 오류 자동 수정 횟수(기본 4), 도면 비교 보정 횟수(기본 2).

## 11. 정확도 점검

`python\python.exe tools\eval_examples.py`는 예제 6개를 모두 AI로 처리하고 기준 모델과 비교하여 축별 크기
오차, 부피 오차, 소요 시간, 빌드 횟수를 표로 출력한다. 모델이나 설정을 바꿨을 때 이것으로 비교한다.

## 12. 문제 해결

| 증상 | 조치 |
|---|---|
| "No AI model is installed" | `models\`에 모델 폴더(`*.gguf`와 `mmproj-*.gguf`)가 있는지 확인 |
| AI 엔진이 시작되지 않음 | Engine log 확인. NVIDIA 드라이버 버전(551.61 이상) 확인, Settings에서 Engine을 Vulkan으로 바꿔 시험 |
| 매우 느림 | 상태 표시줄에서 모델과 엔진(CUDA/CPU) 확인. 모델이 GPU 메모리보다 크면 일부가 CPU에서 실행된다 |
| 뷰나 축척이 틀림 | Drawing 탭에서 뷰 상자 수정 또는 Calibrate, 이후 Build model from these values |
| 빌드 실패가 반복됨 | Code 탭에서 오류 줄 확인, 또는 설명에 "필렛 생략" 등 지시를 추가 |
| 설치 중 "file name too long" | 폴더를 `C:\AICAD`처럼 짧은 경로로 옮겨 다시 설치 |
